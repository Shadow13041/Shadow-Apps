# Shadow Apps

Eine gemeinsame Android-App für Shadow Toolbox, ShadowAI und Shadow Browser.

- Application ID: `com.shadow.apps`
- Mindestversion: Android 7.0 (API 24)
- Java 17 / Kotlin 2.0.21
- Android Gradle Plugin 8.6.1
- Ein Launcher-Eintrag

Die bisherigen Quellcode-Repositories bleiben während der Migration unverändert.
Die drei Funktionsbereiche werden schrittweise in dieses Projekt übernommen.

## Aktueller Stand

Dieses Archiv enthält das Grundprojekt mit Launcher und drei navigierbaren Platzhalterbereichen.
Die eigentlichen Funktionen der drei bestehenden Apps sind noch nicht migriert.
